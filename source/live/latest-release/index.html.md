_Milestone: Zirconium_ was released on March 11th 2017. As our Winter Release for 2016/17 it focused primarily on paying back "code debt" to tidy up the underlying structure of _Three Rings_. It also marks the last of the 'Elemental Class' release pattern we've been using since the launch of Milestone: Aluminium back in June 2008!

[alert\_box type="info" class="corners"]Release notes for previous Milestones [are available here](https://www.threerings.org.uk/help/help/latest-release/past-milestones-release-notes/)[/alert\_box]

#### Performance improvements
As part of an ongoing effort to improve peak-time performance issues, we've been refactoring old and slow code, with a particular focus on the Directory. 
#### List Upcoming shifts for other volunteers
You can now list other volunteers upcoming shifts from their Directory page, provided you have Stats permission. This will be useful to support users who cannot access Three Rings by being able to give them a printout of their future shifts. 
#### Merge Directory fields into Number of Shifts Report
You can now select additional columns from the Directory Report to include in the Number of Shifts Stats report. You might, for example, choose to include a target number of points in a report showing how many points have been accrued over a given period or include telephone numbers in a report showing who doesn't have a shift yet. 
#### Shift Changes Report
A new Stats report that lists changes to shifts (signups, pullouts, confirmations and swap requests) over a date range, by volunteer. 
#### Additional information in Shift History Report
The Shift History report now includes details of confirmations for organisations using this feature. 
#### Resizeable Directory Buttons
Directory Buttons can now be made larger or smaller with a slider. 
#### Change to Directory As Spreadsheet
A new column has been added to the spreadsheets downloaded from Directory to reflect a volunteer's current Inactivity status. 
#### Show presence of Comments on the Rota
Where comments have been associated with a shift, this is now indicated by a speech bubble on the rota - but only if the Organisation uses comments and the volunteer has permission to see them. 
#### Filestore Virus Scanner
We've added a virus scanner to the Filestore just to help ensure nothing nasty gets passed around.
