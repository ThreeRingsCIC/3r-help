#### Adding a New Property

[alert\_box type="warning" class="corners"]Before you start storing any new data, remember to check that you have an appropriate legal basis to store it, and make sure to update your privacy policy and/or other data protection policies if necessary.[/alert\_box]

Click the `Add a Property` button and choose from the list of properties which type of property you'd like to add. You can either scroll through the list of properties, or search for a property using the search bar at the top of the page. Only properties that are not yet in use at your organisation are listed. Click on the property you'd like to add, and then click Add Property.

[alert\_box type="info" class="corners"] If there is a property that you'd to use, which isn't on this list, email support@threerings.org.uk and we'll see if we can add it in the next milestone.[/alert\_box]

You can now configure the new property. Some properties have alternative names that can be used; if applicable, use the drop-down menu to select the name you'd like to use.

Now set who has permissions to view the Property from the `View` field. Properties can be set as follows:

| **All Volunteers** | All users can see this property and any data stored in it. |
| **Directory Managers and owner only** | Only users with Directory:Manage permissions and the user whose information it is can view this property. |
| **Directory managers only** | Only users with Directory:Manage permissions will be able to view the information. (If the user whose information it is doesn't have Directory:Manage permissions they will be unable to see the data!) |
| **Custom** | Allows individual, independent selection of roles that can view the data. i.e. Owner, Committee and Leaders can view this data, but the Training Team and Treasurer cannot. |
| **Nobody** | Prevents **ALL** users from viewing this information. This is the **only** option that prevents users with Directory:Manage permissions from seeing the information. |

Now set who has permissions to edit the property from the `Edit` field (these are the same options as above). [alert\_box type="info" class="corners"] If you select `Custom` you must then also check the boxes next to roles of users you wish to be able to edit the information.[/alert\_box][alert\_box type="warning" class="corners"]Remember that roles in _Three Rings_ are additive, so if a user has a Role that allows them to view or edit a property, and another Role that doesn't, they WILL be able to view/edit it.[/alert\_box]

Next, decide where on volunteers' Directory pages you'd like the property to appear. The existing properties will be listed in the drop-down menu in their current order, and you can select where on the list you'd like it to be added. The new property will be added immediately before the existing property you select.

Finally, to save and add the new property, click the `Add Property` button.

#### Rearranging Existing Properties

Rearranging the order of properties will change the order in which they are displayed in the volunteers' directory pages. Locate the property you wish to move. Click and hold the up and down arrow button and drag and drop the property to where you want it to sit.

#### Editing a Property

Locate the property you wish to edit and click the `edit` button for that property. The `Name:` field allows you to select alternative names for this property by clicking on them. The `Type:` field allows the type of data that can be entered into the field to be viewed. The `View:` field allows you to change who can view this information. To set the desired view permissions, click on the desired option from the drop-down box. Then, click the `Save Changes` button. [alert\_box type="info" class="corners"] If you select Custom you must then also check the boxes next to roles of users you wish to be able to view the information. [/alert\_box]

#### Deleting Properties

[alert\_box type="danger" class="corners"]Warning: Deleting a property (with the exception of Username and Id Number) will delete ALL data stored in that property for ALL your organisation's volunteers. Only delete a property when you are **sure** this data is no longer needed![/alert\_box] Locate the property you wish to delete, click the `Delete` button then `OK` on the confirmation box that appears.
