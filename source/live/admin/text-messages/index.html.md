**Changing your SMS Operator**

Under the heading of Text Messages select your desired provider from the drop down menu.

[alert\_box type="info" class="corners"] Three Rings currently provides support for the third party SMS providers [BulkSMS](http://www.bulksms.com/countries/u/united-kingdom), [BulkSMS Community](https://www.bulksms.com/products/community.htm), [Clickatell,](https://www.clickatell.com/) [AQL](https://aql.com/products/messaging/), [Nexmo](https://www.nexmo.com/) (Vonage), and [Voodoo SMS](https://www.voodoosms.com/). [/alert\_box]

[alert\_box type="warning" class="corners"] BulkSMS (Community Account) is for users who have a Community Account. Normal BulkSMS accounts will not work with this setting, and BulkSMS Community Accounts will not work with the normal BulkSMS setting. If you are unsure which setting to choose, we recommend that you contact BulkSMS. [/alert\_box] Enter your log in details. Then click the `Save Changes` button near the bottom of the page.

#### 

**Defining a Bulk SMS Limit**

Only a few volunteers are likely to need to send texts to large numbers of recipients. These people can be given bulk text privilege via a Role. The value entered here defines a limit to the number of recipients other volunteers are able to select in a single text. Edit this field to an appropriate number and click the `Save changes` button. [alert\_box type="info" class="corners"] Only those with the appropriate permissions can send bulk SMS messages (or even any SMS messages). [/alert\_box]
