Role workflows allow you to set up conditions under which volunteers _without_ access to the Admin tab can assign or revoke selected roles - for example, to allow Trainers to add new roles to volunteers, or Managers to change Probationers to Full Volunteers.

**Existing Workflows**

Existing workflows are listed when you go into the Role Workflows section. You can edit or delete an existing role workflow by clicking the relevant button next to that workflow.

#### Creating new workflows

To set up a new role workflow, click the Define new Role Workflow button.

**Permitted role:** this defines who is allowed to make changes under this workflow. A volunteer with ANY of these roles can make changes. At least one role must be selected here.

**Target must have roles:** this restricts whose roles can be changed under this workflow. Only volunteers with ALL of the roles listed here can be changed. This box is optional and can be left blank.

**Target must not have roles:** this restricts whose roles can be changed under this workflow. Only volunteers with NONE of the roles listed here can be changed. This box is optional and can be left blank.

**Add roles:** this determines which roles will be assigned to affected volunteers when the workflow is used. At least one role must be selected to be added or revoked.

**Revoke roles:** this determines which roles will be removed from affected volunteers when the workflow is used. At least one role must be selected to be added or revoked.

[alert\_box type="info" class="corners"] A workflow can be used to add roles, revoke roles, or do both at the same time. However, a single workflow cannot be used to add and revoke a role. You need one workflow to add it and one to revoke it.[/alert\_box]
