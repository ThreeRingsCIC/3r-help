title: Working with Folders in the Filestore
---

Folders in the Filestore work in a similar way to folders stored on your home PC. You can restrict which volunteers have access to what folders based on their Role, so Folders can be a good way to organise, and limit access to, information

#### Creating a Folder

Click on the Filestore tab at the top of the page and navigate to where you wish to create the folder. Click the `Create Folder,` button at the bottom of the page and enter a name for the folder in the **Folder Name:** field. If you want, you can enter a description for the folder in the **Folder Description:** field. Lastly, click the `Create` button.

#### Renaming a Folder

Navigate to the folder you wish to rename and click the `Rename` button next to the folder. Change the folder name in the first edit box as appropriate. Some special characters are not allowed in folder names, so try to only use numbers and letters. If you want, you can also enter or modify the folder's description in the second edit box. Then click the `Save` button.

[alert\_box type="info" class="corners"] If renaming fails, check there is no other folder with the same name, and try to only use numbers and letters in the folder name.[/alert\_box]

#### Deleting a Folder

[alert\_box type="alert"] Deleting a folder removes it **and all its contents**. Make sure you mean to delete the file before clicking OK! [/alert\_box]

Navigate to the folder you wish to delete click the `Delete` button next to the folder and click `OK`.
