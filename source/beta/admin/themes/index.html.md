## Themes

You can change the display colours _Three Rings_ uses for your organisation here.

[alert\_box type="warning" class="corners"]Changing the theme here will change the default theme for all users at your organisation. To change the theme for yourself, without affecting other users, change it via your [Account](/help/my-account).[/alert\_box]

You can configure _Three Rings_ to use either a single theme, or to sync with system:

- A single theme will always apply
- Syncing with system will mean different colours are used when a device is using dark mode

Select a theme from the drop-down menu. You can then click the Preview button to see what that theme will look like. Once you've selected the theme (in single theme mode) or themes (in sync with system mode), click Save Theme Changes for the theme to take affect.

[alert\_box type="success" class="corners"]One of the available themes is Dyslexia-friendly Default - this theme uses the OpenDyslexic font instead of the usual font, which is designed to make text easier to read for people with dyslexia.[/alert\_box]

Alternatively, you can select Create your own Theme from the drop-down menu. This will allow you to set up customised colours and optionally add an additional logo to display next to the Three Rings logo, for example to match your organisation's corporate identity.

#### Rota Colours

[alert\_box type="info" class="corners"]To change the colours of the rotas themselves, use the [Rotas panel](/help/admin/rotas).[/alert\_box]

You can customise the colours of shifts that are highlighted on the Rota. These are a volunteer's own shifts, understaffed shifts, closed shifts, and the colour used to display 'today'. These colours remain the same across all Rotas at your organisation.
