### Relationships

The Relationships tool lets you create links between different volunteers - for example, Mentor and Mentee relationships. [alert\_box type="info" class="corners"]If you can't see the Relationships panel, you may need to activate the Relationships feature first in the [Features](/help/admin/features) section.[/alert\_box]

#### Adding a New Relationship Type

Locate the edit boxes at the bottom of the page. Name the two sides of the relationship in the First and Second party boxes and click the `Add` button. [alert\_box type="info" class="corners"] It doesn't matter which way round they're set.[/alert\_box]

#### Deleting a Relationship Type

Locate the correct relationship in the list. Click the `Delete` button next to the relationship, and click `OK` to confirm the deletion of the relationship.

[alert\_box type="warning" class="corners"] Deleting a relationship will remove it from the Directory pages of all volunteers currently using it.[/alert\_box]

#### Adding a Relationship to a User

Go to their Directory page, scroll down to the `Relationships` section and click `Add Relationship`. Fill out the pop-up box as appropriate.

### Inactivity

Inactivity allows a period to be set in which a user cannot be signed up for shifts. Inactivity types allow different reasons for absence to be set and treated differently by the _Three Rings_ system. 
#### Creating a New Inactivity Type
 Click the `New Inactivity Type` button. Enter a title for the inactivity type in the `Name` field and select an icon by clicking the radio button to the left of it. Checking the `Email as 'active'` box will mean that volunteers are still able to receive messages sent to `all active` volunteers. Checking `Self-managed` means that volunteers can set this inactivity status themselves (if not, it will only be able to be set by those with `Directory: Manage` permissions). To allow this inactivity type apply to all rotas, leave `All rotas` checked. Otherwise, uncheck it and select the specific rotas you want it to apply to. Click the `Save Changes` button. 
#### Editing an Inactivity Type
 Locate the inactivity type you want to edit in the table and click the `Edit` button for that inactivity type. To modify the name of the inactivity type, enter a new title in the `Name` field. To change the icon, select a new one by clicking the radio button to the left of it. Check any boxes you want to and then click the `Save Changes` button. 
#### Deleting an Inactivity Type

[alert\_box type="warning" class="corners"] You cannot delete an inactivity type that's currently associated with any volunteer (including sleepers).[/alert\_box] Locate the inactivity type you want to delete in the table and click the `Delete` button for that inactivity type.
