Localisation settings control details of how Three Rings presents information to you and your users.

#### Overview

You can define how many days in advance upcoming events are displayed on the Overview. Locate the edit box labelled` Upcoming events limit.` Change the number in the edit box to your desired value. So, if the number is 30, users will be reminded about an event every time they log in for the 30 days before the event to the day of the event itself.

You can also define the default number of days after publication that News Items are auto-archived.

[alert\_box type="warning" class="corners"]This only changes the default - this number can be overwritten on any individual News Item.[/alert\_box]

Once finished, click the `Save Changes` button.

#### Dates and Times

Here is where you set your organisation's time zone. [alert\_box type="info" class="corners"] When the clocks go forward and/or back, there is no need to do anything; _Three Rings_ will automatically update. [/alert\_box] To choose which day is shown as the first day of the week on the Rota, edit the value in the First day of the week dropdown.

To set when one day ends and the next begins, choose an option between Midnight and 11am from the drop down box. To apply these alterations, click the `Save Changes` button at the bottom of the page. This is useful to make _Three Rings_' behaviour match the way your organisation talks about shifts, for example if your organisation calls a shift running from 01:00 to 04:00 on a Thursday morning as the 'Wednesday Overnight shift'.

To set the minutes increment used when selecting times (e.g. for Shifts, Events, etc), change the dropdown labelled Minute step. This can be changed show every minute (1), every 2 minutes, every 5 minutes, every 10 minutes, every 15 minutes, every 20 minutes, or every 30 minutes.

To apply these alterations, click the `Save Changes` button at the top or bottom of the page.

#### Rota Views

Scroll down the page to the section marked Rota Views. To stop a view from being available, uncheck the tick box in the `Available?` column. To re-enable a view, re-check the tick box. To apply these alterations, click the `Save Changes` button at the bottom of the page. To set a view as default, select the right view by selecting the appropriate radio button. To apply these alterations, click the `Save Changes` button at the bottom of the page. To force all users to have the same view, select the right view by selecting the appropriate Force all volunteers to this view link (this is found directly underneath the number of volunteers using a particular view). To apply these alterations, click the `Save Changes` button at the top or bottom of the page.

#### Third Party Calendars

These settings control which public holidays and other events are displayed on the rota calendar. Locate the section of the page entitled Third-Party Calendars. A variety of external calendars are available. You may select as many as you wish to be displayed. To select one, check the box next to its name. To remove it, untick the box. Then click `Save Changes`.

#### Directory Views

Locate the section entitled Directory Views then the drop down box next to `Directory Mode. `Choose to display the Directory as either `Buttons`, or a 'List', then click `Save Changes`. You can also select what information will be displayed underneath volunteers' names on their Directory button. [alert\_box type="info" class="corners"] If most of your volunteers don't use photos on their Directory pages, the list option will probably look better![/alert\_box]
