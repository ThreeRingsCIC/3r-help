This page provides a full list of every past _Three Rings_ Milestone since 2008, together with the official Release Notes.

[alert\_box type="warning" class="corners"]This is a **very** long page! It's here mostly for historical interest, so you can see how _Three Rings_ has evolved over time. For up-to-date Help, you're better off [going back to the Root Help page](https://www.threerings.org.uk/help/help/).[/alert\_box]

## Milestone: Yttrium - November 2016

#### Groups: Role-Based visibility
Role-Based Visibility is a major step forward for _Three Rings_, giving organisations the ability to ‘group’ volunteers together using core Roles, and then set limits on which groups can see other groups. So, for example, you might say that volunteers with the Applicant role _can’t see any other volunteers_, and only volunteers with the Training Team role can see Applicants – if you set things up like this, you’ll be able to store the details of potential volunteers who’ve applied to join your organisation in _Three Rings_ without exposing your whole Directory to them when they log in. Roles-based visibility won’t change anything unless you tell it to, but it forms the next major step towards End-to-End volunteering. You’ll be able to adjust the Access permissions assigned to each Role in Admin \> Roles.
#### Easier bulk adding/removing roles
We expect lots of Organisations will be changing the way their Roles are set up so they can take advantage of the new Groups feature that lets them control Role-Based Visibility. To make that easier, we’ve introduced new tools to make bulk changes to Roles, with new ‘Check/Uncheck All’ boxes at the bottom of the Admin\>Roles\> Add Volunteers page.
#### Date/Time picker improvements
The date/time-picker, is now also used in more places (such as in the 'split shifts' tool). We’ve also improved how it behaves on touchscreens (particularly iOS devices running Safari).
#### Regional rota reporting control
We’ve added a new section to the Admin \> About My Organisation panel which makes it easier for you to select what information is shared “regionally” with any parent organisation you might have.
#### Regional rota reporting date ranges
At the regional/parent organisation level, you can now run a report for specific date ranges, and show either the number of organisations who were or are expected to be open. Parent organisations of federated helplines can also choose to show the number of staffed phone lines that this represents, if they want.
#### Comms - better handling of 'empty' roles
If you type in the names of a set of volunteers _Three Rings_ can’t message in Comms, you’ll now get a clearer explanation of why (for example, if you’ve entered the name of a Role, but nobody with that Role has a valid email address).
#### API expansion
For the benefit of the programmers in your organisations, we've expanded our API (the API is available at [https://www.3r.org.uk/api](https://www.3r.org.uk/api)): it’s now easier for them to write third-party enhancement programs that can be allowed to work with information on your roles, rotas, properties, inactivity types, and relationships.
#### New server infrastructure
We’ve moved _Three Rings_ to a new, more powerful, server. This should mean faster speeds even at busy times. The new server will give Three Rings CIC more flexibility in terms of the server power we can provide, and as the number of users increases. As part of this move, we’re also adopting a new backup mechanism which will maintain our hourly backups without introducing the slowdown some organisations have experienced during the backup at 17 minutes past the hour.

## Milestone: Xenon - August 2016

#### Comms enhancements
In response to some of the feedback we've had since the release of Milestone: Watson, we've made further improvements to the new Comms interface. In addition to working better with tablets, you can now click on Names, Roles, or Gender Properties you've already typed into the To: field to get more information on which volunteers the recipient boxes cover. The secondary interface behind the ellipsis (...) icon has also been given a more intuitive layout, and inactivity icons are now included at this level, as well as in the recipient boxes in the To: field. Full details on [how to compose a message in Comms](https://www.threerings.org.uk/help/help/comms/writing-a-message-in-comms/) (including [our first ever Video Tutorial](https://www.youtube.com/watch?v=70jhSJaiKk0)!) are available from the Help page.
#### Longer shifts and shift editing interface changes
You can now have shifts that run for up to a week, replacing the old limit of 23 hours 55 minutes. We've also made it possible to select the exact minute a shift starts and ends, instead of the old five-minute intervals picker. As part of this change, we've made improvements to the user interface for shift editing, using a normal date/time-picker as used elsewhere in _Three Rings_, instead of a drop-down list of possible shift durations.
#### News minor edit option
When editing a News item, you can now mark your change as a "minor edit". If you do, the change won't be mentioned in the weekly digest for your organisation.
#### Rota drag/drop enhancements
In supported browsers, if you're drag-and-dropping a volunteer on the rota, any shifts that volunteer is already signed up for will now be ghosted', making it easier to find a valid spot for the volunteer you're dragging.
#### Calendar view
A new rota view, Calendar, has been made available which _only_ shows upcoming events. You can enable and disable this option in the Admin \> Localisation panel.
#### New Volunteer Properties and Organisation Properties added
By popular request, we've added a selection of new Directory properties (visible under Admin\>Properties) and Organisational properties (visible under Admin \> About Your Organisation).
## Milestone: Watson - May 2016
_Milestone: Watson, [as this blog post explains](https://www.threerings.org.uk/2016/05/06/help-pages-and-where-milestone-watson-gets-its-name/), was given its name because there weren't any elements whose names begin with a W._
#### Comms overhaul
[When sending messages in Comms](https://www.threerings.org.uk/help/help/comms/writing-a-message-in-comms/), you can now type into an auto-completing field to specify which Volunteers or Roles a message should go to (in addition to the old ‘checkboxes’ method). You can also double-click on Roles to see which volunteers have that role. These changes are reflected in Admin\>Email Options, so you can use the same new interface to specify for example the default recipients of a new Comms message. **Draft Messages Saved in Comms** If you abandon a part-written Comms message (for example because your session ended and you were logged out), you can now come back to it and carry on from where you left off: _Three Rings_ will save the draft in your web browser. **Delete Sent Messages from Comms** If your organisation has a large number of Sent messages logged, you can now delete some to ‘tidy up’ the page (the message details will still appear in Admin\>Logs). 
#### New Properties and updated Properties interface
We've changed how administrators select the [Properties](https://www.threerings.org.uk/help/help/admin/properties/) their organisation uses, and added in new properties like Preferred Contact Method, for organisations who would like the ability for volunteers to say which contact method they prefer. We’ve also added new Properties for more social Networks, and for sensitive demographic information such as Ethnicity, Sexuality, Religion, and Disability. 
#### More Flexible Gender Properties
As part of the Properties overhaul, we've updated the Gender property to be less binary and more-inclusive. Admins can now configure a wider range of genders to be represented within their Directory. Optionally, they can also tell _Three Rings_ to use the gender-specific ‘Man’ and ‘Woman’ instead place of the existing sex-specific ‘Male’ and ‘Female’. 
#### Weekly Digest now includes shift gaps
Volunteers receiving the weekly digest will now see a list of gaps and swaps they’re free to sign up for in the coming week. 
#### Increased font size in the editor
The text used to write news, Comms emails, Wiki pages, and so on is now bigger, and looks more like the text size elsewhere on the page. 
#### Suggest Somebody can be run without the option to sign volunteers up
You can now set whether Suggest Somebody will automatically sign a volunteer up to a shift, or simply give a list of the best matches and an easy link to send them a message through Comms. 
#### Email attributes included in Last Login report
Administrators can now use the Last Login report to to see which users have verified their email addresses, have opted out of receiving emails from _Three Rings_, or are receiving the weekly digests. 
#### Email everyone on a given shift
All volunteers with permission to send emails can click on a shift and start composing an email to all volunteers signed up to that shift, directly from the pop-up window. 
#### Control access to news items
You can now restrict View permissions on News to specific Roles – so you can have some News that’s only visible to volunteers with a particular Role, or are part of a specific team. 
#### Role Simulator
Admins can now simulate what _Three Rings_ looks like to volunteers with fewer roles, [using the Role Simulator](https://www.threerings.org.uk/help/help/admin/deleting-simulating-lending-roles/) in Admin\>Roles to temporarily ‘surrender’ some of their Roles for the remainder of their session. Log out and in again to go back to normal! 
#### Filestore ‘Share’ button
It's now even easier to link a Filestore file from a Comms message, or get a link you can paste into an instant message: just click the ‘Share’ button next to any Filestore file. 
#### New Stats Report and additional download capabilities
We’ve introduced a new [Roles report](https://www.threerings.org.uk/help/help/stats/export-rotas-and-last-login/) in Stats which lists shows which volunteers have what Roles. This can also be exported to .pdf, .csv or Excel files. We’ve also added the option to download the Shift Gaps, Shift Closures, Last Login, and Most Recent Shifts reports as .pdf, .csv or Excel files. 
#### Improved Maintenance Tasks
You can now re-check maintenance tasks on demand in [Admin\>Maintenance](https://www.threerings.org.uk/help/help/admin/maintenance-and-invoicing/) – useful for confirming if you’ve fixed the underlying cause of each!

## Milestone: Vanadium - February 2016
**Speed improvements** We've made Three Rings faster! You'll especially notice the difference when hopping between different tabs on the main menu and in the Comms tool, when using a modern web browser. **Changes to System Logs** Organisations can now choose whether to hide or display iCalendar subscription messages in the system logs. Also, "inline views" of files in the Filestore when they're included in news items on the Overview are no longer logged (currently this applies only to photos). **Move / Copy shifts improved** The interface to Move / Copy shifts has been improved and capability increased. Shifts can now be moved or copied within a day and copying signed-up volunteers is now optional. Shifts are now selected only if they fall entirely within the specified period. **New Property** We've added a new Property that you can add to your Directory, if you wish: Dietary Requirement or Dietary Preference. If you've got properties you think we should be adding, let us know: we can often add new properties at short notice. **New Event Types** By popular request, we've added six new event types for you to select from: Maintenance, Visitor, Lecture, Outreach, Information or Selection.
## Milestone: Uranium - December 2015

#### Email verification and email notification options
Volunteers can now verify the email addresses via their Directory or My Account pages. Volunteers who've verified their email address can opt-in-or-out of various kinds of notifications. This includes a new subscription option: volunteers can opt-in to a "weekly digest" - an automatic weekly email sent every Monday morning with a reminder of their shifts over the next fortnight, upcoming events, and recent news.
#### Default Landing Page
Organisations can now set what page users are shown when they first log in. This can be switched between Overview, the Rota, the Directory, their Account Page or their Upcoming shifts. The option is found under Admin-\>Localisation: note that changes here won't affect users with self-managed accounts.
#### Filestore enhancements
It's now possible to upload multiple files at once, either by clicking the button and selecting them as usual or by drag-and-dropping them from folders on your computer (e.g. from the Desktop). A progress bar is shown while uploading. Note that it's not possible to upload folders in this way. Also, the Filestore user interface has been improved for small-screen devices.
#### Localised logs
Dates and times on the Admin-\>Logs panel will now be shown in your local timezone including respect for Daylight Saving, rather than in UTC. Administrators can specify the timezone for their organisation in the Admin-\>Localisation panel.
#### Comms and Wiki visual editors support browser spell-checkers
If you're using a web browser with spell-checker support, you'll see red-underlined words where you've made spelling mistakes when writing emails and editing wiki pages.
#### Rota Administration permission
This new permission level allows holders to create, delete, etc. shifts on selected rotas without them necessarily having full administor permission.
#### News and Events Self-manage permission
These new permissions allow volunteers to create, edit and archive their own events and news items without giving them control over events and news items that they didn't personally create.
#### Volunteer Inactivity Report improvement
A column has been introduced to the Volunteer Inactivity report, in the Stats tab, for comments to separate them from the dates and make the report clearer
#### Shift Titles optionally displayed on the rota and in reports
In Admin-\>Features it is possible to enable the display of shift titles on the rota and/or in reports.
#### Inactivity symbols in the Rota Volunteer List optional
The inactivity symbols in the Volunteer List at the top of the Rota (for rota managers) have always reflected the _current_ inactivity status of volunteers. This has lead to some confusion among people who felt that they should show their status during some or all of the period being looked at in the rota instead. If you'd rather not show these icons at all, you can now configure whether or not the symbols are displayed via Admin-\>Features.
#### Blankable Date properties in Directory
Dates in the Directory (e.g. dates of birth) can now be cleared using the date picker.
#### Copy to Me enabled by Default
Every email that you send will be copied to the sender as the default action. This behaviour can be toggled on and off for a whole organisation via the Admin-\>Email panel or for each individual message via the Copy to Me box at the bottom of the Comms page.
#### New Weather Icons
The weather icons have been updated to to account for a wider range of weather conditions and to fit in with the new look-and-feel.

# Milestone: Technetium - July 2015

#### My Account: 'Primary' Organisation
Users that volunteer at more that one organisation using the same account can now specify a 'primary' organisation which will be automatically selected on login. Their other accounts with other organisations remain accessible via the 'My Account' page. This is useful for users who use their account to volunteer in multiple places but most-often want to log in to just one.
#### News: Add images from the Filestore
After you've uploaded images in web-safe formats (e.g. JPEG, PNG) to the Filestore, you can now insert them easily into News Items by clicking the new "Image from Filestore" button in the toolbar. Simply select the image and it'll appear in your news item. Note that volunteers will still need permission to see that image in the Filestore or else they'll see a blank space in the News Item, instead!
#### Wiki: WYSIWYG and enhancements
We've overhauled large parts of the wiki feature. Your wikis now have a WYSIWYG editor just like the one used for news items, which makes it easier to edit content as well as making it possible to add tables, images, special characters, and different formatting styles to your wiki pages.
#### Comms: Copy to Me
A new checkbox appears at the bottom of your message in the Comms tab: check it to specify that you want a copy of your message to be sent to you as well.
#### View Invoices
You can now view details of all your organisation's invoices via the Admin -\> Invoices panel.
#### Stats -\> Shift Closures and Shift Gaps
The background colour of rotas is now included on these reports to aid rapid visual identification.
#### Upcoming Shifts and Gaps
Accessed from the Overview, this tool now differentiates between required shifts and optional shifts and allows volunteers to select swaps and gaps from multiple rotas.
#### Shift history
The history of a shift, including who signed up, when and who dropped out can now be viewed from the shift tab in the rota. Permissions of who can view the shift history can be controlled on a per rota basis from the rota permissions (for organisations already using Three Rings, it will default only to roles that have access to the Admin -\> Logs panel). There is now also the ability to compile a report of shift histories for multiple roots and dates in stats.
#### Nexmo available as SMS provider
[Text messaging provider Nexmo](https://www.nexmo.com/) offers a good-value text messaging service (about 2p per message to UK numbers, at current exchange rates: other destinations may vary), so we've added support for them to Three Rings alongside BulkSMS and Clickatell. They'll give you €2 of free credit to try them out (good for around 60 messages), if you'd like to give them a go.
#### Three new Properties
We've added three new Properties that you can apply to your Directory, if you wish: Medical Conditions, Support Required, and (Shift) Frequency.
#### Style standardisation
Continuing from work earlier this year, more parts of Three Rings have been given a more-consistent style. Date and time pickers, Directory pages, and Event creation/editing are the major parts to be re-skinned this time: but the changes are subtle, and you shouldn't have any difficulty finding the features you're used to.
#### Improved Android support
Users of Android mobile phones using the stock web browser will have a better experience of the Overview (as news administrators) and Comms sections.
# Milestone: Strontium - April 2015

#### "Core" roles
It's now possible for an organisation to define several roles of the type that we call "core" roles: that is - roles that every volunteer must have at least one of. Previously, organisations have always had exactly one core role, called 'Everyone', and this has been automatically assigned to all volunteers. If you want to carry on using Three Rings that way, then you can, but it's also now possible to instead have multiple core roles: for example, a helpline could have different core roles for 'Helpline Volunteer' and 'Support Volunteer', and give a different baseline of permissions to each. These baseline permissions, taken from a volunteer's core role(s), can still be supplemented using other roles (including other core roles). If you've ever found yourself thinking that you need a way to reduce the permissions that a volunteer gets, using a role, but you don't want to reduce the permissions on the 'Everyone' role, then core roles are for you.
#### Filestore enhancements
The Filestore now sports a faster and slicker interface including a new 'tree view' that helps you find exactly what you're looking for. It's also now possible to move files and folders (by drag-and-dropping them around the Filestore), to sort files and folders by name, size, or description, and to view certain types of files (just image files, for now) directly in your browser without having to first save a copy to your computer: this also makes the Filestore suitable for images shown in News Items, for the adventurous.
#### Inactitivity improvements
It's now possible to delete inactivity types that are no longer needed, assigning any existing inactivity periods defined against them to a different inactivity type or deleting them altogether. There are also now three times as many icons to choose from to identify your inactivity types, the order in which inactivity types appear on lists can be specified, and volunteers setting inactivity can leave a comment to give further detail about the inactivity. It's also now possible to specify an "upper limit" to the duration of inactivity, by inactivity type (so you can say, for example, that being "On Holiday" - which volunteers can manage for themselves - can last no longer than 3 weeks; longer than that and you need to contact an Directory Manager who can put you "On Sabatical").
#### Unique volunteer identifier added to Stats \> Shifts / Hours
A number of people have asked to be able to combine information from the Directory with information from Stats reports. This will be made easier by having a matching volunteer identifier in both reports, which is a step in the right direction for those among you who like to do your own data processing.
#### Rota Selection added to Stats \> Service Delivery
It's now possible to show only selected rotas on the Service Delivery report.
#### Event list enhancements
A number of features have been added to the event attendance list to improve management. Event administrators can now sign up and delete volunteers from the sign-up list. There is also an ability to make the list public so that everyone can see who has signed up along with the event information. Errors, such as if the list is full are now more helpful and the event description includes how many volunteers out of a possible maximum number have signed up as well as a message to say if the sign-up period is closed
#### Purge volunteers from maintenance task
When an administrator clicks on the maintenance task reminding them to purge volunteers that have been slept for over a year, there is now a link whereby the administrator is able to achieve this. The page includes the list of volunteers who have been slept for over a year along with a tick box. The admin can then decide to select a certain number to purge or purge all of them. Finally there is also a tick box on the page to allow admins to dismiss the maintenance task. If they have purged all volunteers in question then the maintenance task is automatically dismissed.
#### Export Rotas
This feature allows a user who has access to the Stats tab to export the rota in a variety of ways. The first is from the "Export Rotas" section of the Stats tab. The report displays all shifts' start and end date and times along with the names of the volunteers on that shift. This can either be displayed as a table on the web page or there is an option to export the data as a csv file. Further options for exporting include using the API (described at [https://www.3r.org.uk/api](https://www.3r.org.uk/api)), where the user can export the data in json or csv format
#### Request swap on affected shifts when going inactive
When going inactive affected shifts will be displayed for the period in question. If the organisation uses swaps there is now an option to request a swap on all selected shifts rather than just pull out of shifts.
#### Add description to roles
Admins can create a description along with the name of a role. This description is displayed in the Admin-\>Roles table when clicking on the name of the role, so you can keep track of the purpose of certain roles (especially useful for anybody who's recently taken over as an administrator).
#### Comms Improvements
The Comms interface has been improved as part of our ongoing efforts to standardise our look-and-feel. The SMS character counter now behaves more-accurately when sending multi-part text messages, and - using the Admin-\>Email Options panel, administrator can specify a prefix to be placed before the subject of every email.
#### Rolling Rota Views
Two new rota views are available, Rolling Week and Rolling Month. These are similar to Week and Month views respectively except they start with the current day-of-week, which makes it harder for volunteers to accidentally neglect shifts near the start of next week by failing to click the "Next \>\>" link.
#### Bulk Sleeping of Volunteer accounts
The option has been added to the Stats / Last Login report to put the accounts of multiple volunteers to sleep. This will be particularly useful to resolve issues of volunteers who haven't logged in for a long time as highlighted by the Maintenance Tasks.
#### Updated My Account Page user interface
An improved design for the My Account page makes it easier for volunteers with multiple accounts to fit them all onto the screen at once, as well as showing the roles they hold in each of their organisations.
#### Invoice Details Page
You can now view and update the details we use to generate your annual Three Rings invoice from the Admin tab.
#### First steps in standardised look-and-feel
We've been making efforts to standardise the look-and-feel of Three Rings, especially the forms and tables, so that they all have consistent layout, spacing, and button styles. The first parts of these changes are now in place, but there'll be more to come in future releases.
#### Two new properties
We've added two new formatted text area properties in which you can store volunteer information - "Comments", a generic area that can serve as an additional space to keep notes on volunteers in addition to "About Me", and "Exemptions", in case you've got volunteers whose agreement/commitment level includes special rules about shift types that they won't be asked to do. Remember that we're happy to consider any suggestions for new properties that your organisation will use, and accepted suggestions are normally added in the very next release of Three Rings. 
# Milestone: Rhenium - January 2015

#### Keys overhaul
Major changes have been made to the Keys feature: administrators will need to reinstall all of your keys by clicking the Install button on the Admin-\>Keys panel. New-style keys are faster to request, easier to install, work in more different browsers, have additional security features (including tools to help you track where they're installed and remotely 'revoke' them from specific computers if need be), produce friendlier error messages when they go wrong, and better-support new technologies that we hope to roll out in the future.
#### Sign-up to events
Ability for volunteers to sign-up to say they're attending an event. Events now have an option to receive sign-ups as well as further options to control the maximum number of volunteers that can sign-up as well as a closing date. Volunteers can also leave a comment on the event once signed-up that can be viewed by event administrators. An option is also available for event administrators to download the sign-up list.
#### Hiding purged sleeping volunteers
The Directory now hides sleeping volunteers whose details have been purged, by default. You can display them again by clicking a link.
#### Improved calendar synchronisation
Google Calendar (and other web calendars) should now automatically update when somebody signs up to a shift alongside you (or pulls out), if you're subscribed. We've also improved the user interface for subscribing to your calendar, to make it easier to choose whether you want to download a one-off snapshot or to subscribe to future updates.
#### Creating accounts for people who already have Three Rings accounts elsewhere
Volunteers with Three Rings accounts at multiple organisations recently gained the ability to merge these accounts after converting them to 'self-managed' accounts. We've now extended that functionality so that, when first creating the account for a new volunteer, you can link it to their existing self-managed Three Rings account: all you need is their username.
#### Support for "emoji" characters
Previously, if you tried to use your smartphone to enter "emoji" characters (standardised graphical smileys and emoticons) into news items or comms messages, you would see an error message. We now support these special symbols so you can enter them freely (however, note that not everybody's phone or computer can show them, or might show them differently).
#### Fewer "Error 500s" at busy times
We've fixed a major cause of an otherwise-harmless kind of "Error 500" that could occur when one or two people try to make the same change at the same time (the change always went through, but one person would see an unfriendly error message).
#### Better support for Safari on MacOS
The visual editor used for News and Comms previously caused problems when used in some versions of Safari on MacOS; this should now be fixed.
#### Various bugfixes and performance improvements
As usual for a maintenance release, we've added a variety of general improvements to fix bugs, enhance speed, security and stability, accelerate Three Rings, and support future development.
#### New property
The "DBS Certificate Number" property has been added to Three Rings. If you have any particular properties you'd like to see in Three Rings, let us know: these can usually be added in the very next release. 
# Milestone: Promethium - July 2014

#### Self-Managed Accounts
Volunteers can optionally choose to turn their accounts into "personal accounts", which they manage for themselves, rather than having them managed by the organisation where they volunteer, from the new "My Account" page. This enables them to choose their own username, reset their own password, and use a single username and password to log in to all of their Three Rings accounts (if, for example, they volunteer in multiple places).
#### Admin-\>Security tab
This new admin panel allows organisations to choose whether or not volunteers with personal accounts will be automatically allowed back into their account after a password reset, or whether they'll still need to contact a support person. Of course, the default setting is the most-secure option.
#### Two-Factor Authentication
Volunteers who have switched to a "personal account" can opt to secure it more-thoroughly using two-factor authentication. Three Rings supports either Google Authenticator (on your smartphone) or a YubiKey? (on your keyring). Security-conscious organisations can make two-factor authentication mandatory for volunteers accessing the Admin tab, if they like, using the new Admin-\>Security tab.
#### Visual editor for News and Comms
We've added a modern, visual editor, allowing you to edit news in a "WYSIWYG" way. Additional tools make it possible to add images, styled "blocks", multi-level lists, tables, and links (with special helpers to make it easier to link to people's Directory pages or to files in the Filestore). A slightly cut-down version of the editor appears in Comms, too, so you can now send emails with enhanced formatting options, including links to Filestore files!
#### CTRL-Drag on Rota
Holding down the CTRL key while click-and-dragging a person to a different shift will copy them, rather than moving them, making it easier to fill a number of shifts with the same person.
#### Exportable Log
Administrators can now export extracts of the log to CSV for further analysis (e.g. in Excel). In order to limit the volume, new date range controls have been put on the log page. These controls also apply to the on-screen display.
#### Ordering of news items
News items can now be prioritised within their category (sticky or non-sticky). When a news item is created it will have a priority of "medium", but can be promoted to "high" or demoted to "low" to influence the ordering of items on the overview page. Press the "more" button on the news item to reveal the up-arrow (promote) and down-arrow (demote) functions.
#### All day shifts
Shifts can be marked as being "all day". This automatically sets the duration of the shift to be 24 hours and places it at the start of the day on the rota in the new "all day" category.
#### Titles and comments on shifts
Administrators can now add titles to shifts, to specify additional information about them. Titles also appear in iCalendar exports/subscriptions, where present. It's also possible for users of particular roles to be allowed to "comment" on shifts, for example to leave notes on their travel arrangements or other information that might be useful to fellow volunteers. These features must first be enabled from the Admin-\>Features panel.
#### Improvements in Stats Reports
We've added tools to help filter volunteers by roles, and to indicate periods of inactivity, when using the Number of Shifts/Hours/Points? report. This should be especially useful for rota managers to see who might be available for future shifts and those who haven't signed up yet. Also: the Last Login report now shows current inactivity, and the Shift Gaps report includes day names.
#### Post-Signup Window Autopopulator
The Autopopulator and Suggest Somebody features can now be run for dates beyond the Signup Window for a rota. To enable this, go to Admin-\>Rota Automation and edit your rulesets, ticking the 'Ignore Signup Window' box. With this feature, organisations that operate a "managed" rota can more-easily fill their rotas ahead of the period in which they allow their volunteers to self-manage.
#### Rota more-readable even when dark colours are used
Previously, if you made a rota 'black' or another very dark colour, it'd be hard to make out the text on each shift. Now the rota will intelligently turn the text white if your shifts are dark in colour, making it easier to read them.
#### iCalendar subscription update improvements
If you subscribe to "your shifts" using your personal calendar (e.g. Google Calendar, Yahoo! Calendar, iCal, or Outlook) then the events in your calendar should now automatically update to indicate who you're on shift with, if somebody signs up or pulls out alongside you.
#### Speed improvements
Some parts of Three Rings have been streamlined and should be faster than ever before, such as the "sign up" window, especially if your organisation makes extensive use of availability. 
# Milestone: Osmium - April 2014
**Roles & Experience Levels Merged** Experience levels are gone - everything you could do with them you can now do with roles! Amongst other things, this means you can now have more than one default role for new volunteers, and you can assign roles when you create accounts; additionally, signup rules now allow you to model more complicated situations. **Shifts in non-weekly patterns** Until now, it's only been possible to create shifts that are either "one-off" or which occur regularly, each week. As of Miletone: Osmium, it's now possible to create shifts that occur fortnightly, tri-weekly, etc., on a particular day of the month (e.g. 3rd day of month), or on a particular occurance of a day of the week in the month (e.g. 2nd Wednesday). **Move or Copy shifts** Administrators can move or copy shifts between rotas. This should be of benefit to people running managed rota and will make initial setup of rotas simpler. **"Fixed" rota headers** In supported web browsers, the dates (in week view) and the days of the week (in month view) will stay "fixed" to the top of the screen when you scroll down, making it easier to see which day you're looking at, especially on long rotas. We've also applied "fixed headers" to the Admin-\>Rotas, Admin-\>Roles, and Admin-\>Closures tabled, and to the Directory in "...as list" view. **Stats Gap Report** A new report in the Stats will list all gaps over a defined time period. Note that the Upcoming Gaps facility (on the Overview page) only lists gaps to which that user can sign up. **Stats Volunteer Inactivity Report** Lists volunteer inactivities over a user defined time period. This should make it simpler for rota sectretaries to see who has been inactive in the past or will be inactive in the future. **Stats Closed Shifts Report** Added rota selection so you need only report on the rotas you are interested in. **Personal Hours / Points Total** Individual Directory pages now show the volunteer's shifts in terms of points and hours as well as stars. Also when you hover over the star you are able to see the points and hours it contributed (if any). All users can see their own points, whether or not they can see each others is controlled by a new feature (under the points feature) called "Allow volunteers to see each other's point" **"Confidentiality Agreement" properties** New properties have been added to track whether or not confidentiality agreements have been signed, and/or on what date. 
# Milestone: Neodymium - January 2014
**A new look** we've applied Three Rings' new brand identity and colours to the Three Rings application, giving it a fresh, modern look. The new design also works better on mobile phones and other narrow-screen devices. The new design tries to make the most of the screen space available, laying out content in the best way possible for your screen, so it looks even better than ever on ultra-wide monitors, too. **Shift splitting** administrators can "split" a shift into two shifts, making it easier than ever to manage those unusual times that you need two shifts in the space that one usually stood. **Most Recent Shifts 'Overall'** In the Most Recent Shifts report in the Stats section, a new "Overall" column has been added so you can see more easily when a volunteer did their last shift and when they have their next shift across all rotas. You can also select which columns you wish to see displayed. **Languages Spoken Property added** As requested by the Best Tester of a previous Milestone, it's now possible to allow your volunteers to state the languages in which they're fluent, right on their Directory page. As with all other Properties, you're in control over who has permission to see and/or edit the values of the languages property. **Apply "Minimum Time Between Shifts" Rules across multiple rotas** A second feature requested by a Best Tester. We've extended the minimum-time-between-shifts signup rule systm to allow you to set restrictions across multiple rotas - for instance, you could now say that volunteers have to leave three days between shifts across both the Daytime and Overnight Rotas. While we were at it, we've given signup rules a little tidy up to make them easier to understand and use. **Refactoring** as Neodymium was produced during our Winter development cycle - the part of our schedule that we focus on improving what we've already got rather than on producing new features - we've taken the opportunity to dramatically expand our automated test suite and improve the fundamentals of Three Rings. This helps to keep Three Rings bug-free now and in the future, and makes the system faster and more stable.

# Milestone: Lutetium - August 2013
**iCal feed for shifts** Clicking on the "you have X upcoming shifts" at the bottom of the Upcoming Events list takes you to a list of your upcoming shifts; at the bottom of this list is a new button. Click this to download a "calendar file" with the details of your upcoming shifts, which you can import into Outlook, Apple Calendar, Google Calendar, Yahoo! Calendar, or any other standard calendar software. Or if your calendar software supports "subscribing" (automatic updating), then you can right-click on the button and copy the address/link, and paste it into your calendar software to automatically synchronise your personal calendar with your upcoming shifts list. **More visible Event details** Hovering over any event on the rota will give you more details about that event. Useful for finding out what's happening without having to click into the event. **Certificates -\> Keys** Certificates have been renamed to Keys, to avoid confusion over exactly what they do. Keys can be used to assign additional Roles to volunteers who use a particular computer (e.g. to give volunteers in your office rota management permissions, or access to particular Filestore folders) or to disable the automatic time-out (e.g. for "always on" wall-mounted rota screens). All your existing Certificates will continue to work as Keys. **Filestore improvements** You can now control access for individuals files as well as folders, and each folder has a number next to the name to tell you how many files are in it. **Log search** Search for specific text in log messages to track things down more quickly and precisely. **Delete Wiki pages** You can now delete unwanted Wiki pages, to tidy up your old wikis. **Improved shift listing when going inactive** From now on, the list of your current shifts displayed when you're going inactive will be ordered by rota to make it easier to use. **Speed improvements** We've made a few boosts to the slowest parts of Three Rings, by improving the way that our database works and by not loading data until you need it: you might notice that the Directory ...as buttons list will load more names at once and then fill in the photos afterwards, to give you the most-important information first, rota managers will find that the rota loads more-quickly, and organisations that use the auto-populator may find that performance of this tool has been boosted as well. 
# Milestone: Krypton - June 2013

**Control over the permissions of individual Directory Properties:** From the Admin-\>Properties panel, you can now set permissions on individual Properties shown in the Directory. For example, you can make volunteers' "Emergency Contact Details" visible only to the Committee and the volunteer themselves, or you can make Email Address editable by "semi-manager" volunteers who aren't able to edit other Properties. There's a great deal of flexibility in the new permissions model, but remember: if you choose to store information about volunteers that those volunteers themselves can't see, make sure that you're obeying the UK's Data Protection Act (or similar legislation in your country).

**Rearrange and rename Directory Properties:** While you're in Admin-\>Properties, you'll find that you can re-arrange the Directory fields, and even give them different names: so if you'd rather call it "Christian Name" or "Forename" than "First Name", or to rename "Emergency Contact Details" to "ICE Contact", you can.

**View sent messages in Comms:** All volunteers will now be able to view the content of messages they've sent through Three Rings' Comms system. This feature will only show messages sent after Krypton is released.

**Volunteers may override their own unavailability:** Where the rota options permit it, volunteers can now sign up for shifts during periods when they are marked as unavailable. Like the admin override system, they'll have to tick a check-box to perform the override.

**Improved System News:** System News is now properly separated from Org news, and individual volunteers can dismiss items of system news or even opt out of receiving certain types of news completely.

**Save as My Default for the Directory:** You can now save your Directory "...as list" view as your personal default, just like you can with the Rota: just check/uncheck the columns you'd like to see, then click "Save as My Default".

**Maintenance Tasks:** Three Rings will now remind your administrators when there are tasks overdue, with a new panel in the Admin tab. You'll be advised if you've got large numbers of sleeping-but-unpurged volunteers (helping you keep on the right side of the Data Protection Act), accounts that have never been used, no nominated Support People, or other maintenance issues that need your attention.

**Expanded Comms gender filtering checkboxes:** By request, the gender filtering checkboxes in the Comms tab will now let you filter by the gender of any volunteer at your organisation.

**Improvements to 'inline' Directory editing and New Volunteers:** We've streamlined the process of editing Directory pages, so that even if you're editing "inline" (clicking the 'edit' link next to each property you want to change) you can still edit multiple properties at once. We've also synchronised the Directory with the New Volunteer page, so you can edit any or all of your Properties right as you create each new account.

**Tighter auditing of Three Rings staff:** If you ask a member of Three Rings staff to log in to your organisation, that'll now show up in your logs, including which Three Rings volunteer logged in and the reason for their doing so.

[alert\_box type="info" class="corners"]Prior to Milestone: Krypton, _Three Rings_ releases were monolithic: specific objectives were set at the start of the release cycle and the Milestone was not released until they were all complete. From Krypton onwards, releases became Fixed, working on a regular schedule to ensure that completed features weren't kept waiting by others that were still a work in progress.[/alert\_box]

# Milestone: Jethrik - October 2012
**Drag-and-drop on more rotas** The drag-and-drop features have been expanded so that they now work on Fortnight View and Month View rotas, too (on supported web browsers). **Different-coloured stars for different rotas** You now have the option to use different-coloured stars to differentiate between shifts in different rotas, when displayed as a starchart. It's a great way to make night shifts or leader duties "stand out" on volunteers' Directory pages, to help make them feel proud of their achievements. **Suggest Somebody and Autopopulate separated** You can now set yourself up to use one without the other, or turn of Rota Automation entirely, from the Features panel in the Admin tab. **Three new Properties** After some discussion with Three Rings Users on the Discussion List and elsewhere, we've added three new properties that you can enable for your organisation: Commitment (which you can optionally rename to Expectation, Agreed Contribution, Target, or one of any number of other things to best-fit what you call it), Training, and Car Registration Plate. **Improvements to information shown in the Directory** We've made it possible to show popular properties like Relationships and Slept At dates (when viewing sleepers) in the list view, and we've made it easier to check the checkboxes at the top. And once you're on a Directory page, we've tidied up the way that Markdown properties like About Me are displayed so that they don't take up so much space (even when you're using bulleted or numbered lists). **Lists of Temporary Passwords** When you're bringing on board new volunteers in bulk, it's a pain to have to reset all of their passwords individually. Now you can see all of the temporary passwords for your new volunteers from the Last Login report on the Stats tab (only for Admins). **Improved Directory searching** By popular request, the Directory search box now appears on more Directory pages. You can also now search by "Volunteer Number" rather than by name (so long as your volunteers have names in the form of "Alice 123", you can just search for "123" to find Alice), and the search box will try to help you to auto-complete the name you're thinking of. **Take Directory photos with your webcam** If you've got a webcam and a compatible computer, you can now change your Directory photo just by smiling and clicking a button. Three Rings will take the photo and save it to your Directory page: now there's no excuse not to have a picture on your profile. **Smart picture resizing** Upload (or snap with your webcam!) a picture to the Directory and you'll now be able to choose how to crop it for the "...as buttons" Directory view, leading to better pictures of you and your fellow volunteers. **News item unarchiving** By popular request, News: Managers can now restore archived news items back to the Overview page, if the need arises. **Smarter Recurring Shift checkboxes** When you sign up to a series of shifts, the weeks you can't sign up to because you're already signed up or inactive now appear, but cannot be selected: this makes it a lot easier to select "every fortnight" or similar patterns of shifts. **Easier to use Admin panels** Following feedback from you, our users, we've made the Experience Levels and Rules panels in the Admin tab easier to use, with simpler controls and the ability to edit rules and experience levels without having to delete and re-create them. **Harder to accidentally send duplicate emails** When you've clicked the "Send Message" button in Comms, Three Rings now won't let you click it again until the message has been sent, preventing you from accidentally clicking it twice. **Store web addresses and social network accounts for your organisation** You can now set your organisation's web site and social network (Twitter, Facebook, LinkedIn, and Google+, right now) account and share them with your volunteers or with other organisations in your organisation's family, if you like. **Better Rota performance in Internet Explorer** For those of you who have to wrestle with Internet Explorer, we've streamlined some of the inner workings of the Rota to make it as fast as it is for other web browsers. And if you're using Internet Explorer 9 or above, you'll now also get the fancy drag-and-drop "highlighting" effect that the users of the other browsers get, too. **Better security against "brute force" attacks** If you can't remember your password and keep trying to guess, you might notice that Three Rings asks you to slow down and will make you wait for a minute before you carry on. That's the result of a valuable new security feature that makes it almost impossible for hackers to keep guessing passwords until they get one that works. The technique's called "tarpitting", and it's based on the idea that a minute's delay is a minor inconvenience to a legitimate user who just needs one more guess to remember their password... but it's a huge barrier to a hacker who has a list of a hundred thousand passwords to try! **New autopopulator setting: "Preferred Shifts Only"** Allows you to set up autopop to only give volunteers shifts during their 'preferred' times. **Number of selected volunteers displayed in Directory** When viewing a list of volunteers in the Directory, you can now see the total number currently selected (just to the right of the drop-down box). **Improved support for text messaging** We've added features to help configure Three Rings to support text messaging across the telephone networks of countries outside of the UK, for the benefit of our international users. And for everybody, regardless of their country, Three Rings now produces better and clearer error messages when things go wrong, to make it easier to get set-up with text messaging to begin with. And, as usual, lots of little things...

# Milestone: Hafnium - February 2011
**Track volunteer availability** Allow volunteers to specify the times that they can and cannot work (and, optionally, the times that they prefer to work), and this will be reflected in the drop-down lists when you sign them up for duties. Now if you work 9-5 or run a salsa dancing class on Wednesday nights there's no need to get a phone call asking you to do a shift when you simply can't! Turn this new feature off or on using the Features panel in the Admin tab, and manage it using the new Availability section on your Directory pages. **Book your holidays in advance** Periods of "inactivity" - when a volunteer isn't doing shifts for a while, whether that's because of a holiday or any other reason - can now be booked in advance, and you can set up as many as you like. **Drag-and-drop rota management for rota administrators** If you're a rota administrator, you're now able to drag-and-drop volunteers around the rota. This feature currently only works in Week View, but it's a great way to quickly make amendments to your volunteers' schedules: just grab them and put them where you want them. There's a "Volunteer List" button at the top-right of the rota to make the process easy. Please note that this feature is only supported in the most modern web browsers: users of older web browsers may have to stick with the old-fashioned way. **Focus on the important things** Click on the "Yours" or "Understaffed" coloured bars in the top-left corner of the rota to highlight where these shifts are: so you can quickly find the places that you're on duty, or find where there are problems. **Share information about your organisation** You're now able to conveniently share information about your organisation - such as contact details and services provided - with other volunteers. This information can be shared exclusively within your own organisation (so you can use it, for example, to keep your volunteers up-to-date on door access codes) or with other organisations within your organisational family - the organisations affiliated to yours. So you could choose to let your regional team know who to contact if they want to get in touch with you, or let other similar organisations know how many volunteers you've got at any given time. Nothing is shared unless you specifically allow it, but we hope that you'll feel able to use this tool to learn more about your neighbours and to better keep-in-touch with one another. **Track Mentor/Mentee? (and similar) relationships** The new Relationships feature of the Directory (once configured from the Admin panel) gives you the means to track Mentor/Mentee? relationships in whatever form your organisation follows (mentors, aunts/uncles, the bourbon system, etc.), whether transitory in nature or permanent. I'm sure you can think of other uses for this flexible tool, too. **Better management of newly-training/shadowing volunteers** When setting up rules, you're now able to configure your rotas so that volunteers with particular Experience Levels don't count towards the "required" and/or the "maximum" number of volunteers on a shift. So you can say "New Volunteers don't count towards the 2 volunteers needed on a shift," and you'll still get coloured bars to let you know that you need two non-New Volunteers on that shift, to accompany the New Volunteer that signed up. **Email with style** We've enhanced the Comms tools so now you can use styles (like bold, italic, and lists) as well as hyperlinks in your emails. Further changes to Comms should mean that you're less likely to find Three Rings emails in your "spam" folder, and you can opt to have your emails customised so that the recipient gets details of their next upcoming shifts in the footer of the message. **More-customisable rota colours** Using the Localisation panel, you can now customise even the colours of "yours" and "understaffed" shifts, making it even easier to make Three Rings look the way that \*you\* want it to. We've also made it easier to use the rota colour colour-pickers, and provided clearer error messages when things don't behave as you'd expect. **Customisable "Upcoming Events" window** Using a new option in the Localisation panel, you can choose how far in advance you'd like your volunteers to see events in the Upcoming Events list: anywhere from 1 day to 60 days. **Filtering of personal starcharts** When you're viewing personal starcharts (i.e. those on a volunteer's Directory page), you can filter the shifts shown down to just those within the last 12 months, or those within a particular calendar year. **Three new properties** By popular request, it's now possible to store the following new data properties about your volunteers: CRB Issue Date, Occupation, and Internal ID. **Choose the Directory default view mode at your organisation** If you've got a lot of volunteers, you might prefer it if they saw the "...as list" Directory view by default, rather than the "...as buttons" one. You've now got the power to make this happen, from a new option in the Admin-\>Localisation panel. **More-tolerant Activation Codes** Entering Activation Codes is a less error-prone process, thanks to a more tolerant Activation Code checker and more meaningful error messages, making it easier for new volunteers to get started. **Fewer ways to get error messages when logging in** We've always taken Three Rings' security systems very seriously, and sometimes they've been known to misfire, giving people the dreaded "error 422" when they try to log in from particular computers or with certain configurations. We've relaxed these very slightly, reducing the likelihood that legitimate volunteers will ever see one of these ugly warnings.

# Milestone: G-124 - September 2010
**Dramatically improved accessibility** For users who use a screen reader or braille pad to access Three Rings, there are now special features which should allow full access to the site through an accessible interface. Just click "Accessible Version" in the top right to switch to the Accessible Version of Three Rings, which is laid out in a way that should be compatible with all major accessibility software. **Features control panel** We've added a new button to the Admin tab, "Features". You can use this button to disable parts of Three Rings that you don't want to use (for example, we're aware that many organisations don't care for the "confirmation" feature on the rota, or don't want to worry about the wiki). By turning off features here you reduce the risk of accidentally granting access to them, and help the Three Rings team to see what features are being most-actively used, and focus our efforts accordingly. **Improved Directory display options** It's now possible to change Experience Levels without using the Edit page, view Directory search results in list and button view modes, and more - all of this packed up in a convenient space-saving drop-down box on the Directory page. **Directory export** One of the most popular requests in recent years: it's now possible to export the results of any Directory list or button view as either a Comma Separated Values (CSV) file (capable of being opened in virtually any spreadsheet package) or as an Excel file, enabling you to keep backups of your data, easily format and print your own Directory lists, run your own mail merges, and more. By default, your Directory: Managers will get this new feature, but you can associate the new "Directory: Download Spreadsheet" permission with the appropriate roles in your own organisation. **Directory sorting** When viewing the Directory "...as list", it's now possible to sort by any of the column headings by clicking on it. Click again to reverse-sort, or shift-click to set up secondary sorting. **Directory filtering by role** Previously only accessible to administrators, we've now made it possible for regular volunteers, too, to filter the Directory by role. Just click on the name of the role from the Roles column (in list view) and you'll see everybody who holds that role. You can also click the name of a role on an individual's Directory page to see everybody else who holds that role. **Smarter Directory thumbnails** We've noticed that the tool that makes the thumbnail pictures for the "...as buttons" Directory view will sometimes crop off the top of people's heads! This is because when taking photographs, it's most-common for the face of the subject to appear in the upper-half of the frame, but Three Rings used to crop with a focus on the centre of the frame. But no more: it's not much smarter, but landscape-oriented Directory pictures are now more-likely to cut off people's foreheads. Note that this only applies to newly-uploaded Directory pictures, and doesn't affect the pictures already on your Three Rings Directory. **Changable usernames** Your administrators can now change the usernames for your volunteers. **Comms Send "By Role"** You can now send e-mails and text messages to all volunteers with any specified role (or roles), giving you a new and easy way to get in touch with your team. **Streamlined role administration** Whether you're adding a new role or changing an existing one, the admin panels now feature a streamlined interface to make it clearer who has what permissions, with help that tells you only about the permission you're changing right now. **"No-timeout" Certificates** If your organisation has an office that's staffed all or most of the time, you might already be using one of a number of unsupported "workarounds" in order to keep the Three Rings session in your office from expiring, allowing you to keep the rota up-and-running at all times. Obviously this poses a security risk, but - done properly - that risk can be mitigated. The new "No-timeout" Certificates feature provides a supported way to do this, leveraging the facilities already provided by Three Rings Certificates. If you want to use it, you'll first need to enable it in the new Features panel, and then set it up via the Certificates panel. **Export Activation Codes** The Activation Codes list can now be exported as either a Comma Separated Values (CSV) file (capable of being opened in virtually any spreadsheet package) or as an Excel file, so it's easy to run your own mail merges to distribute activation codes to new volunteers. **Easier to create new Rotas and Shifts** Thanks to user feedback, we've picked up on what the most common mistakes are when creating new Rotas and their Shifts, and we've streamlined the process along with helpful messages (rather than error messages when things go wrong). **Security tightening on assignment of Roles** As part of a security review, we've made it so that only those with Admin access can add or remove roles from volunteers (as opposed to those with Directory: Manage, as was previously the case). This prevents a malicious volunteer with Directory: Manage permissions from getting Admin access by giving themselves an administrator's Role. **Add Directory links to News and Events** A new button when you're editing News Items or Events makes it easy for you to make links to volunteers' Directory pages. **Support for BulkSMS "Community Accounts"** This service gives preferential rates for SMS services to charities, and is now supported by the Three Rings SMS system. **Clearer warning when deleting shifts using Closures** You should now have to tick a box to say you definitely want to delete shifts in this way, in a similar fashion to over-riding the rules on signups.

# Milestone: Gallium - May 2010
**Smarter (less annoying) timeouts** Perhaps the most common complaint we've gotten over the last year is that it's annoying to be half-way through typing an e-mail, news item, or wiki page, when the system times out and you have to re-enter your password. Now, the system will attempt to intelligently detect if you're working on something, and will hold off on logging you out so long as you're still typing. **Closing shifts** We all hate it when we have to close down our shifts, and maybe that's why it took so long for Three Rings to support this much-requested feature: but now it's here - shifts which didn't meet their minimum volunteer requirements, or which were planned to be closed in advance, will now be marked as shut down on the rota and reflected in the statistics. **Directory "...as list"** It is now possible to view the Directory in either the classic "buttons" (pictures) view, or as a list of volunteer details which is suitable for printing. The volunteer list can be customised by showing or hiding fields like telephone numbers, e-mail addresses, and experience levels. **Improved indication of inactive volunteers** Anywhere in Three Rings where you can click on a volunteer and bring up their 'card', the card should now show if that volunteer is inactive. **The rota that remembers how you work** If your organisation has multiple rotas (e.g. On Duty and Leader rotas), and you rarely look at the Leader rota (because, perhaps, you're never a leader, just a regular volunteer), this feature is for you. Just uncheck the rotas you don't want to see, as normal, and then press the "Save as My Default" button to tell Three Rings not to bother you with that rota in future unless you specifically ask for it. Don't worry: you can change it back just as easily. **Sortable 'Most Recent Shifts' report** The 'Most Recent Shifts' statistical report, which provides information on each volunteers next and last shift, can now be sorted on any column. Simply click on the text at the top of any column in this report to order by that column (by volunteer, or most recent/next shift on any given rota). **Directory "Slept At" date** When viewing the details of a "sleeping" (account closed) volunteer, the date and time at which their account was "slept" is shown. **Ability to delete directory photos** You asked for it, we did it. There's now a link below the photo (for all volunteers who have photos) which allows you to delete it without putting up a different picture. **Extra Directory Properties** Administrators can now enable access to two new instant messenger properties - Skype, and Google Talk - which can be stored on Volunteers' Directory pages. Other additional properties are: "CRB Passed", a checkbox field allowing you to record whether or not your volunteers have had a CRB check, and "Telephone (Work)", where you can record work phone numbers separately from home and mobile numbers. As usual, both new properties are turned off by default - to start using them, simply visit Admin -\> Properties and change them from 'None' to 'Admin only' (allowing only admins to edit their values) or 'Self managed' to permit volunteers to update this information themselves. **Easier Photo/Password Changes** It's now easier for volunteers to change their Directory photo or their password by using convenient links on the right-hand side of their Directory pages. In fact, we've made a number of Directory settings easier to change, using links on the right hand side of the volunteer you're editing: give them a go. **Activation Codes admin panel** When adding volunteers in bulk, it's now simpler to produce a simple list of all of the new usernames and their activation codes, for distribution by whatever means best suits your organisation. Just click the Activation Codes button in the Admin section. Note that this can only be used to bulk-generate activation codes for volunteers who have never logged in. **Localisation settings** Want to start the week on a Sunday? Want your late-night overnight shifts to appear at the end of the previous day? Now you can, using the Localisation panel in the Admin section. You can also choose to restrict which rota views are accessible to your volunteers, and better control the circumstances under which birthdays appear on the Overview page and on the Rota. **Choose your own rota colours** You're no longer constrained to drawing your rotas in the colours we offer - now administrators can change the colour of each rota to whatever colour suits you best, whether that's a soft, calm green or a hot, energetic pink. **Linkable, refreshable rota** A common complaint in earlier versions of _Three Rings_ was that it was not always possible to bookmark, copy, or refresh specific weeks or months on the rota without being forced to return to "today". This has now been resolved. **Event Type icon previews** When you're selecting a type of event to create, you'll see a preview of the icon associated with that event type, where available. There's also a new event type, "phone", for when you need to set up reminders for callbacks and similar occurances. **Easier-to-read "long" rotas** For those of you with "long" rotas with many shifts shown at once, it can be hard to have to scroll back to the top of the page every time to check what date range you're looking at or to click the "Previous" or "Next" links. To make it easier, _Three Rings_ will now automatically put this information at the bottom of rota pages where the rota requires scrolling, so you'll spend less time scrolling back up a page you've just scrolled down. **More information in volunteer cards**"Pop-up" volunteer cards now contain information about the most recently done and next upcoming shifts for the volunteer you clicked on, making it even easier to find the best person for the shift you're trying to fill. **Improvements to regional statistical tools** The regional coverage tool (currently only in use by Wales & the Marches Samaritans) now shows today plus seven days (rather than "this week"), and gives information in terms of number of branches open rather than number of lines available. **Fewer constraints on shift times** You're now able to start a shift at any minute of the day, not just at quarter-hour intervals. **Access to many new settings** Many settings which until now could only be activated via the back-end, by the _Three Rings_ support team, can now be set by administrators at your organisation: it's time to re-explore the Admin tab! **Improvements to filtering and controls on Number of Shifts stats report** Previously, sorting by volunteer or number of shifts would mean that you lost any selections of rota or date range you'd made. Now, these controls work more intuitively. **Simple view 'bulk signups'** It's now possible to sign up to multiple shifts at once from the Simple View, saving volunteers using this view lots of clicking. This feature should be of particular use to visually impaired volunteers, who often find the Simple View easier to navigate with accessibility tools. **Holidays are now called Closures** Holidays - periods of time during which a rota is shut down - have been renamed to Closures in the Admin panel, in order to reduce confusion between it and the "Inactive" status of volunteers who, for whatever reason, aren't doing shifts for a while.

# Milestone: Erbium - July 2009
**Shift validation improvements** We're improved the way that shifts report that they could not be filled. Previously, for example, if a regular volunteer tried to sign up for a shift that had been simultaneously filled while the volunteer was looking at the page, they would simply be confronted with an eternal "Please wait..." and a spinner, or an unfriendly error message. Now, they should be presented with a basic explanation of why the shift could not be signed up. **Swaps** The new 'Swaps' feature allows volunteers to request that someone else takes over their shift. When a volunteer requests a swap, this is indicated on the rota and other volunteers can sign up to the slot as if it were empty. However, the volunteer will not be pulled out of the shift unless somebody else signs up in their place. Swapping has a separate grace period from pulling out, so you could allow volunteers to ask for a swap with less notice than they would need to give to pull out. Swapping is turned off for all rotas by default - to turn it on, go into the 'Rules' page in the 'Admin' tab and change the 'Swap Grace Period'. **Week and fortnight view style change** By popular demand, the week view rota now shows the shifts centered in any given day, similar to the other rota views. In addition, the "colour" chosen for particular rotas is now more-clearly used as the background on week and fortnight views. **Future signup window ("sliding window")** Several organisations have approached us to ask if it can be made possible to limit the amount of time in advance for which signups can be permitted. This can now be done by setting a 'signup window' on the 'Rules' page of the 'Admin' section (it can even differ by rota). Using this, you can - for example - prevent your volunteers from signing up more than 6 or 8 weeks in advance, to better fit with your organisation's policies. **Recurring signups** It's now possible to sign up a series of shifts in the same slot every week (or in a number of concurrent weeks). To allow this, use the Rota Permissions panel in the Admin section of the site to set a permission level at which volunteers can use the recurring signup feature (some organisations may want Self-Managers to be able to do it, others will want to restrict it to Managers, whereas others still won't want to use it at all). When clicking a "sign up" link, these volunteers will have the option to check a checkbox to sign up for multiple shifts simultaneously, in the same weekly slot. They can check a series of checkboxes to do this. This integrates with everything else in this release, such as the signup window period (so it isn't possible to sign up further in advance than the window) and the new shift validation system (so if you attempt to sign up for a series of shifts, but you can't sign up for some of them - e.g. somebody beats you to them - you will see a message explaining which ones couldn't be signed up, and why). We anticipate that this feature will make it far easier for busy rota managers to populate their calendar: and might also encourage regular volunteers to consider signing up for their favourite weekly shift for a longer advance period, too! **Attribution of news** News items on the Overview page are now attributed to the volunteer who last edited them, not the volunteer who created them. This should reduce the confusion that can be caused when news items are recycled rather than being thrown out and re-created. **Signup undo periods** Using the 'Rules' panel under 'Admin', it's now possible to set a "signup undo period" - a number of minutes after signup during which the person signing up a shift is permitted to pull it out again, regardless of whether the rules would normally allow them to pull out at such short notice. For example, with a signup undo period of 3 minutes, if a volunteer signs up for tomorrow's shift, they have 3 minutes to "change their mind" and pull themselves back out again, even if the grace period for their organisation would not normally allow them to pull out of a shift that's happening as soon as tomorrow. This tool provides a safety net for volunteers, so that simple mistakes can be corrected by Self-Manage volunteers without having to bother a rota manager for help. 
# Milestone: Deuterium - April 2009
**Password checking** - all new passwords should be required to be at least 8 characters long and contain a mixture of letters and numbers. **New look rota!** - we've changed the appearance of the rota in several ways, and added a new 'One Week' view, designed to be easier for orgs that run lots of shifts. **Directory stats** - the personal statistics on users directory pages should now be divided by rota - this was an oversight in the last release. **Most recent shifts stats** - these should now be in a more sensible order for orgs with more than one rota. **Delete confirmations** - if you try to delete anything anywhere in Three Rings (like a rota, or a piece of news), you should now get a dialogue box to check you meant it. **Going inactive** - when you go inactive, you can now set a date when you will return (and the system will set you active again on that date). You are also given the option to pull out of any upcoming shifts. **Service delivery stats** - now have a pretty graph. **Better rota management** - it's now possible to rename and delete rotas. **Data protection tool** - to help everyone keep up with their data protection responsibilities, we've put in the ability to purge all personal data from an account when putting a volunteer to sleep, or at any time afterwards. Please note this is a one way operation - purged accounts can't be unpurged. **Directory search** - from the main directory page, you can now search for a volunteer by any of the 'name' fields (username, first name, surname and friendly name). **Confirmable shifts** - it's now possible for volunteers to 'confirm' shifts which were entered for them by an admin (shifts they signed up to themselves are assumed to be confirmed already). Confirmed shifts are marked on the rota with a green tick. **Simple Version** - the simple version main page now shows news and events, and the directory page shows photos as well as contact details. **Adding volunteers to a role** - it is now possible to choose any role from within the admin/roles section and choose volunteers to add to it. This can be quicker than going through individual volunteer's directory pages. **Standardized times** - all times shown anywhere on the site should now be in the 24 hour clock (previously we had a mixture of 24 hour and 12 hour notation). **Better treatment of holidays with no name** - in the stats section, holidays with no name could cause some confusing entries to appear in drop-down boxes. Well not anymore! **Quick link from simple to full versions** - there's now a matching link back from the simple version to the full one in the same place as the simple version link appears in the full one. **Much faster loading times for stats/number of shifts report.**
