[alert\_box type="info" class="corners"]In order to use Filestore, it must be enabled in features, and you must have a role that grants at least view permissions for the Filestore.[/alert\_box]

#### Navigating the Filestore

Click on the `Filestore`, tab at the top of the page. If there are any, files and folders will appear. To open a folder or a file, double-click on it. To return to the root directory, you can either use your browser's back button, or use the path controls near the top of the page. The names of folders in the path displayed are links: the root is on the left and your current folder on the right (and other folders in the middle will be in the middle). If you click `Show Tree`, the files will be displayed to the left-hand side of the page. Clicking on the folders and files is also another way of viewing and navigating the Filestore contents. `Hide tree` will remove it from view.

[alert\_box type="info" class="corners"]The Show Tree button and feature is only visible on wider screens, and is automatically disabled on mobile devices.[/alert\_box]

#### Folder Permissions

If you have the relevant Filestore permissions, you can set permissions within Filestore limiting which Roles can view each Folder's contents. You can set permissions to `Read & Write`, `Read-only` or `No Rights`.

Volunteers with a role that includes Filestore Manage permission will always be able to Read & Write files. If you have files you want to password-protect, you can usually save the file with password protection in the application you use to create it (for example: Word or Excel) and then save it in the Filestore in the usual way. Only volunteers with the password would then be able to access the contents.

[alert\_box type="warning" class="corners"]If a Role has no rights for a folder, they won't be able to see any subfolders within it, even if they have Read or Read & Write permissions on those subfolders.[/alert\_box]
