## Shift Closures

The ‘Shift Closures’ option provides details on when shifts have closed. To access these statistics, click the `Stats` tab at the top of the page, and then the `Shift Closures` link. The system will automatically show shift closures for the past four weeks across all rotas. You can change the time period of the statistics by using the two calendar buttons at the top of the page, selecting the dates between which you wish to view statistics, and clicking `Refresh`. You can change the shifts covered by the statistics by ticking or unticking the relevant checkboxes, and clicking `Refresh`. In addition to viewing this report online, you can optionally download it as a PDF, or as a .csv or .xls spreadsheet: links to do this appear below the report.

## Shift Gaps

The 'Shift Gaps' option will display all shifts which were understaffed, but which did not close. To access these statistics, click the `Stats` tab at the top of the page, and then the `Shift Gaps` link. The system will automatically show a table of shift gaps for the past four weeks across all rotas. You can change the time period of the statistics by using the two calendar buttons at the top of the page, selecting the dates between which you wish to view statistics, and clicking `Refresh`. You can change the shifts covered by the statistics by ticking or unticking the relevant checkboxes, and clicking `Refresh`. In addition to viewing this report online, you can optionally download it as a PDF, or as a .csv or .xls spreadsheet: links to do this appear below the report.

## Shift History

The Shift History report allows you to show all the changes that happened to shifts on a given Rota or set of Rotas between two dates. You can select which Rotas to run the report against using the drop-down, and set the Dates the report should study with the calendar buttons at the top of the page. The report will show who was signed up or pulled out of shifts and (if another volunteer did it on their behalf), by whom. If your organisation has enabled the 'Confirmation' Rota Enhancement in Admin \> Features, the Shift History report will also tell you the date and time each volunteer confirmed their shift. Optionally, you can export this report in .csv format for editing in an external program.

## Shift Changes

The Shift Changes report shows you every sign-up and pull-out a volunteer made to shifts on a given Rota or set of Rotas between two dates. You filter the report to show specific sets of volunteers by Role, and can select which Rotas to run the report against using the drop-down, and set the Dates the report should study with the calendar buttons at the top of the page. You can also include a range of Directory Properties to be included in the report, and can export the finished report as a .pdf or .csv format.
