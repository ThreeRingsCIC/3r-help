#### Setting Your Message Type

Select the type of message you want to send from the first drop-down box. Either **Email** or **SMS**. [alert\_box type="info" class="corners"] If your organisation has not enabled SMS messaging, you will not see this option. If your organisation has SMS enabled, you must have sufficient SMS credits to send the message.[/alert\_box] For more information about sending SMS messages, see the relevant section in the Admin tab. Select who the message will appear to be from. The value for this is usually pre-defined via Admin\>Email settings. Then choose who the message will be sent to and set the message subject.

#### Selecting Recipients

You can choose who will receive your message by sending to:

- Individual volunteers
- Every volunteer with a certain Role or Roles
- All volunteers with a particular Gender set in their Directory page

To do this, just type their Names, Roles, or Genders into the '`To'` field, just like you would when composing a new email. You can add as many recipients as you like, and 'mix and match' Roles, Names and Genders as you need. As you type, _Three Rings_ will automatically suggest matching Names, Roles and Gender properties, based on your organisation's settings:

[![Screenshot showing how typing a name into the Comms To field brings up a list of suggestions](https://www.threerings.org.uk/wp-content/uploads/2016/05/Comms-To-Field-1024x440.png)](https://www.threerings.org.uk/wp-content/uploads/2016/05/Comms-To-Field.png)

When you see the drop-down of matching suggestions you can click on the one you want to immediately select all matching recipients (for example, everyone with the 'Training Team' Role). You can do this multiple times, so it's possible to use the auto-complete feature to quickly select both the Training Team and Committee Roles as the recipients of a message. If you've entered the various recipients in a random order, you can alphabetise the list by clicking on the '`ABC↓`' button to the right of the '`To`' box. This will automatically sort every Name, Role & Gender you've typed into the '`To'` field into alphabetical order, which can make it easier to double-check you're sending to everyone you need to include. **To check which volunteers are covered by a Role or Gender Property** that you've typed in as a recipient, you can click on that Role to view a pop-up box which will tell you how many volunteers covered by that list have valid email addresses stored in _Three Rings_.

[![NewNewComms Popout](https://www.threerings.org.uk/wp-content/uploads/2016/08/NewNewComms-Popout.png)](https://www.threerings.org.uk/wp-content/uploads/2016/08/NewNewComms-Popout.png)

You can use this popup box to either `Expand` or `Remove` that Role or Gender property from the list of recipients in the '`To`' field. Clicking on `Expand` will explode the list, showing every volunteer covered by that Role or Gender as a separate recipient in the '`To`' field. You can then remove individual recipients by clicking the '`x`' next to their name. Any Inactive volunteers in your list will be shown in a red box, together with an Inactivity icon. Clicking their name will give you the option to remove them from the recipient list.

[![NewNewComms Inactive Liam](https://www.threerings.org.uk/wp-content/uploads/2016/08/NewNewComms-Inactive-Liam.png)](https://www.threerings.org.uk/wp-content/uploads/2016/08/NewNewComms-Inactive-Liam.png)

#### Alternative 'Checkbox' method for entering recipients

If you're not certain which Roles, or Volunteers you want to send your message to, and therefore can't start typing their names into the '`To`' field, you can use a 'checkbox' interface to select recipients instead of entering them directly. To access the checkbox lists, click the Ellipsis (`...`) icon to the right of the '`To`' field. You can use the Tabs in the checkbox view to show either All checkboxes, or just checkboxes to select recipients by Role, Volunteer, or Gender Property. Volunteers who are currently Inactive are marked with an Inactivity icon beside their name.

[![NewNewComms Checkboxes](https://www.threerings.org.uk/wp-content/uploads/2016/08/NewNewComms-Checkboxes-1024x233.png)](https://www.threerings.org.uk/wp-content/uploads/2016/08/NewNewComms-Checkboxes.png)

When you're done ticking checkboxes you can click the 'OK' button to insert your selected recipients into the '`To`' field.

#### Composing Your Message

Enter the message content. In the large edit box, enter the information you wish to send to the other volunteers. There are several tools that allow you to apply different effects to the text in your message (including Bold and Italic text). If you hover your mouse over them, a short description of what the button does will appear. You can include an image through the content editing tools: this only works if you have a URL for the link or if the file/image is in the Filestore.

#### Deleting a draft message

_Three Rings_ will automatically save a draft of a half-composed message in case you accidentally leave the Comms page. To scrap the saved Draft, click the 'Discard Draft' button.

#### Message Footer

A footer may be appended to the message which details the name(s) of the volunteer(s) to whom the message is being sent. You can select which footer is included (or choose to send no footer), using the drop-down menu here. Additionally a footer outlining the recipient's future shift(s) may be included - this is usually set by default for the whole organisation via Admin\>Email settings.
